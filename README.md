# VidFlow

VidFlow is a lightweight web application that turns any video into a complete, study-ready lesson. Upload a video and the app uses Google Gemini AI to generate a structured summary, learning objectives, key points, a full transcript, and a knowledge quiz.

No authentication required — just upload and learn.

---

## Features

- **No Login Required** — Open the app and start using it immediately. There is no sign-up, no accounts, and no session management to worry about.

- **Video Upload** — Drag & drop or click to select an MP4, MOV, or WebM file (up to 500 MB). The uploader accepts common video formats and enforces a size limit to keep processing fast.

- **AI-Generated Learning Content** — Powered by Google Gemini, which transcribes the video's audio and intelligently structures it into a full lesson. No manual note-taking required.

- **Structured Summary** — A concise overview of the video's core subject matter, so you can grasp the main idea at a glance before diving deeper.

- **Learning Objectives** — Clear goals for what you should understand after reviewing the material. These help frame your study and set expectations.

- **Key Points** — A bulleted list of the most important takeaways, making it easy to skim and revise the critical concepts.

- **Full Transcript** — The complete text of the video, useful for searching, quoting, or reading along at your own pace.

- **Knowledge Quiz** — Multiple-choice questions generated from the video content, with a running score and a final result at the end so you can test your understanding.
